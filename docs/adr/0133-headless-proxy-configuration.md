# ADR-0133：无桌面服务的显式 HTTPS 反代管理

- 状态：已接受
- 日期：2026-11-03
- 修订：ADR-0105 的配置管理访问边界

## 背景

单人 VPS 部署使用前置 NGINX 的 HTTPS 域名访问。原无桌面策略拒绝所有带转发头的配置请求，导致登录后仍无法通过域名管理。

## 决策

- 默认继续只开放本机与私有网络管理。无桌面入口可用 `PEACH_CONFIG_PUBLIC_ORIGIN` 显式授权一个完整 HTTPS origin。
- 同时核对 `FORWARDED_ALLOW_IPS` 中逐个列出的实际代理 IP，以及已启用的登录凭据；不接受通配符、主机名或网段作为公网配置授权。
- 复用 Uvicorn 解析代理头，在解析前保留实际连接地址，禁止外层提前重写连接来源；不根据浏览器 IP 或自行声明的转发地址授予权限。
- 配置读写、配置入口显隐和诊断使用管理授权；宿主机播放器与本机免认证分支继续使用原本机策略。
- 保留现有会话认证、同源校验、修订冲突检查与原子保存，不更改数据格式或配置重载协议。

## 验证

隔离回归覆盖域名登录、配置读取与持久化、默认拒绝、错误代理或域名、HTTP、缺少实际连接身份、未登录、跨源提交和关闭凭据；线上部署另行验证实际 HTTPS 域名与配置保存。
